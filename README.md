# 의료급여 지원업무 조회 및 집계

`web/index.html`은 정적 웹페이지입니다. 배포 후 업무데이터 CSV와 기관현황 CSV를 각각 브라우저에서 선택하면 카드 검색, 다중 필터, 최신순 정렬, 우수기관 만족도 상위 5개를 표시합니다. CSV 내용은 서버로 전송되지 않습니다.

`solution.py`는 Python 표준 라이브러리만 사용합니다. 두 CSV를 `upload/` 폴더에 넣고 `python solution.py`를 실행하거나 `--work`, `--org`, `--output`으로 경로를 지정합니다. 입력 파일은 저장소에 포함하지 않습니다.

Netlify 설정: 저장소 연결, 기본 디렉터리 `web`, 빌드 명령 없음, 게시 디렉터리 `web`.
